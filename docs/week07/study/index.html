Which firms export?

Firms differ in productivity. Fixed export costs select the strongest firms into foreign markets.

Observe: few firms export and fewer dominate export value.

Explain: productivity lowers unit cost.

Predict: lower trade costs change who exports.

Measure: entry, exit, intensive growth, and reallocation.

One derivative gives the best quantity

For inverse demand p(q) = A − q/2, delivered marginal cost m, and fixed cost F:

π(q) = (A − q/2 − m)q − F

First-order condition

π′(q) = A − q − m = 0

q* = A − m, with π″(q) = −1 < 0.

Profit at the optimum

π* = (q*)²/2 − F

Try first, then reveal

1. Why can two firms in the same industry make different export decisions?

Different productivity creates different unit costs and margins. Only sufficiently productive firms can cover domestic and export fixed costs.

2. Does an exporter productivity premium prove learning by exporting?

No. Productive firms may self-select into exporting. Identifying learning requires tracking firms and isolating changes caused by export entry.

3. Why can aggregate productivity rise if every surviving firm’s productivity stays fixed?

Low-productivity firms can exit and market shares can shift toward high-productivity firms. The weighted average then rises through selection and reallocation.

4. Which cost should mainly affect the number of exporters?

A fixed export cost. Lowering it moves the export cutoff left, so some domestic-only firms begin exporting.

One-sentence summary: trade is concentrated because fixed costs select productive firms into exporting, and trade then reallocates activity toward those firms.

A five-step recipe for a linear-demand firm problem

  1. Compute costs: c = w/a and delivered m = c + t.
  2. Write the problem: p(q) = A − bq and π(q) = [p(q) − m]q − F.
  3. Optimize: differentiate, set π′(q) = 0, and check π″(q) < 0.
  4. Plug back: after finding q*, use inverse demand: p* = p(q*) = A − bq*. Then compute π*.
  5. Decide: enter or export if and only if π* ≥ 0.

Symbolic result

π′(q) = A − 2bq − m
q* = (A − m) ÷ (2b)

MR determines the optimal quantity; demand determines price. With b > 0, π″(q) = −2b < 0.

Classroom shortcut

b = 1/2  ⇒  q* = A − m

Memory rule: F is absent from the first-order condition. It changes entry, not q* conditional on entry.
